# Reference board

Study these products for craft — then adapt to EduBridge’s **light-only, institutional + AI-native** identity. Do not clone dark-first or developer-only aesthetics as the product theme.

Roundup with patterns: [SaaS dashboard examples 2026](https://adminlte.io/blog/saas-dashboard-design-examples/).

| Site | Steal this | Do not copy blindly |
|------|------------|---------------------|
| [Attio](https://attio.com) | AI summaries as **designed components**; bright canvas; product chrome as hero | Their exact blue; marketing-only density |
| [Stripe](https://stripe.com) / [Dashboard](https://dashboard.stripe.com) | Tables as primary UI; microstates; calm data | Generic “fintech purple” |
| [Mercury](https://mercury.com) | Editorial polish that builds institutional trust | Card-everywhere layouts |
| [Linear](https://linear.app) | Quiet chrome, keyboard density, distinct control states | Dark-as-identity |
| [Vercel](https://vercel.com) | Monochrome restraint; color = meaning only | Developer-only tone |
| [Hex](https://hex.tech) | AI analytics as living insight surfaces | Notebook chrome overload |
| [PostHog](https://posthog.com) | One-question insight cards | Playful chaos |
| [Supabase Dashboard](https://supabase.com/dashboard) | Console wayfinding across many tools | Dense console aesthetics for parents |
| [Plausible](https://plausible.io) | Radical simplicity for analytics | Undercrafted marketing |
| [Aceternity UI](https://ui.aceternity.com) | Marketing hero / feature motion vocabulary | Background beams in school admin |
| [shadcn/ui](https://ui.shadcn.com) | Product primitives, Chart, Sidebar patterns | Unstyled default “starter zinc” as final brand |
| [CopilotKit Sidebar](https://docs.showcase.copilotkit.ai/prebuilt-components/sidebar) | Docked assistant beside shell; slot theming to tokens | Default demo styling |

## How to use this board

1. Pick **one** reference for the problem (e.g. Attio for AI summary blocks, Stripe for marks tables).
2. Translate into EduBridge tokens and `@repo/ui` components — never paste foreign hex or demo class soup.
3. Marketing pages may borrow Aceternity motion; workspace modules stay quiet and data-first.
4. If a pattern fights [MASTER.md](./MASTER.md), MASTER wins.
